# v0.5 yerel geliştirme kaydı — 24 Eylül 2026

Durum: HR-017–019 kodu ve yerel doğrulama tamamlandı. Bu kayıt Git etiketi veya yayımlanmış sürüm değildir. Gerçek internet alıcısına webhook gönderimi ve Windows dışı race detector kontrolü yapılmadı; üretim hazır olma iddiası yoktur.

Yönetici, üretici anahtarından ayrı bir token ile hedef oluşturur, okur, URL/anahtar kimliği/etkinlik durumunu sürüm denetimiyle değiştirir. Olay kabulü URL, sürüm ve anahtar kimliğini teslimat satırına kopyalar. Kapatma bekleyen işleri sonlandırır; başlamış çağrı bitmiş olabilir. Varsayılan `public` profili yalnızca HTTPS/443 hedeflerine izin verir. Yerel HTTP demosu yalnızca açık `TARGET_PROFILE=demo` ile çalışır. Dış bağlantı her dial öncesi tüm DNS adreslerini denetler, doğrulanan sayısal IP'ye bağlanır ve özgün host için TLS doğrulamasını korur. Redirect, ortam proxy'si ve keep-alive kapalıdır.

Dış anahtarlar Git dışı ham dosyalardan yüklenir; PostgreSQL ve API yalnızca `key_id` tutar. Yeni sürüme geçerken eski teslimatlar eski anahtarı kullanır. API kabulü, yönetici değişiklikleri ve worker gönderimi süreç içi hız sınırlarına tabidir. Ham depolama/bağlantı hataları loglanmaz; yalnızca güvenli hata türü yazılır. Anahtar hazırlama ve döndürme adımları [rehberdedir](../key-rotation.md).

Go testleri gerçek `hookrelay_test` PostgreSQL üzerinde geçici şemalarla çalıştı; `go vet ./...` ve OpenAPI YAML ayrıştırması geçti. Testler yönetici/üretici ayrımı, hedef kapatma, sürüm çatışması, eski/yeni anahtar snapshot'ı, alıcının iki anahtarı geçişte doğrulayıp eskiyi reddetmesi, DNS/IP engelleri, redirect, `429` ve log maskelemesini kapsadı. Canlı yerel API kontrolünde yönetici listeleme `200`, üretici tokenıyla aynı rota `401`, dış hedef için anahtarsız istek `400` döndü. Kontrol için açılan API kapatıldı.

İlgili kayıtlar: [HR-017](v0.5-hr017.md), [ağ tehdit modeli](../target-security.md), [HR-019](v0.5-hr019.md). Sonraki iş v0.6/HR-020 gözlemlenebilirliktir.
