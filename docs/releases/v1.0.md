# v1.0 yerel kabul raporu

28 Eylül 2026. Bu rapor yerel portföy kilometre taşıdır; Git sürüm etiketi veya GitHub Release değildir.

Boş `hookrelay-hr029` Compose volume'u ile kurulum yapıldı. PostgreSQL 17 sağlıklı başladı, 18 migration uygulandı, API/worker/iki alıcı sağlıklı oldu. İlk örnek olayın iki teslimatı da `succeeded` oldu. Aynı test projesinde şu sonuçlar alındı:

| Kontrol | Sonuç |
| --- | --- |
| İki hedefe ilk teslimat | 2/2 başarılı |
| Aynı idempotency anahtarı | `202`, aynı event ID, replay başlığı; farklı içerik `409` |
| Geçici hata | `500`, `500`, `204`; 3 girişim, başarılı |
| Yanıt kaybı | 2 girişim, alıcıda 1 kalıcı yan etki |
| Sürekli `500` | 5 girişim, `dead`, neden `max_attempts` |
| İç ağ hedefi | `400`, hedef reddedildi |
| Normal yeniden başlatma | `down`/`up -d --wait` öncesi ve sonrası 18 migration, 10 olay, 12 teslimat, 10 alıcı etkisi |
| kind smoke | Mevcut tek node'lu cluster'da yeni olayın 2/2 teslimatı başarılı |

Demo komutları [demo.md](../demo.md) ve [demo-compose.ps1](../../scripts/demo-compose.ps1) içinde. Temiz test projesi durduruldu ve yalnızca `hookrelay-hr029_pgdata` test volume'u kaldırıldı; mevcut kind cluster'ı ve diğer veriler korunuyor.

Önceki görevlerin zorunlu kanıtları: [atomik kabul ve idempotency](v0.3-hr010.md), [worker çökmesi/eski lease](v0.4-hr014.md), [DB kesintisi](v0.6-hr021.md), [yedek geri yükleme](v0.6-hr022.md), [Pod kaybı ve rollout](v0.8-hr026.md). İmza/ağ sınırı ve teslimat davranışı [görev tablosunda](../tasks.md) ve [teslimat sözleşmesinde](../delivery-semantics.md) açıklanıyor. [GitHub CI](https://github.com/hmzckd/HookRelay/actions/runs/36451352513) biçim, vet, gerçek PostgreSQL testleri, Linux race testi ve image build'i geçti.

**Sınırlar:** Dış internet alıcısı, AWS, üretim yüksek erişilebilirliği, otomatik yedek ve gerçek yük kapasitesi doğrulanmadı. Compose/kind tek PostgreSQL örneği kullanır. İlk HTTP yanıtı kaybolduğunda uzak yan etki belirsizdir; demo alıcısı bunu kendi `delivery_id` kaydıyla tekilleştirir. Bu çalışma gerçek alıcılarda tam bir exactly-once garantisi vermez.
