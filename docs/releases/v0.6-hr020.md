# HR-020 — korelasyon logları ve kalıcı metrikler

24 Eylül 2026. API ve worker JSON loglarında olay, teslimat ve girişim kimlikleriyle korelasyon sağlandı. Kabul, gönderim ve kalıcı teslimat kararı ayrı satırlardır; gizli içerik ve ham hata metni loglanmaz. Yönetici anahtarına bağlı `GET /v1/metrics`, PostgreSQL'de tutulan olay/iş/girişim sayılarını, hazır kuyruk ve en eski bekleyen iş yaşını, girişim süre eşiklerini ve API bağlantı havuzunu Prometheus metni olarak gösterir. Etiketler sabittir; ID, URL veya secret içermez. [Kullanım ve teşhis](../observability.md).

Gerçek PostgreSQL entegrasyon testi bekleyen iş yaşını, kalıcı HTTP 400 hatasında `dead`, HTTP 500 sonrasında `retry_wait` ve takip eden başarılı girişimde `succeeded` sayılarını doğrular. HTTP testleri yönetici erişimini, biçimi ve hata metninin yanıt dışı kalmasını; log testi korelasyon ve gizli alanların yazılmamasını doğrular. `go test -count=1 ./...`, `go vet ./...` ve OpenAPI YAML doğrulaması çalıştırıldı. Sistem geneli çok süreçli Prometheus kurulum veya gerçek internet alıcısı testi bu adımın kapsamında değildir.
