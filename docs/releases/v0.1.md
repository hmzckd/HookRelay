# v0.1 yerel kabul kaydı — 23 Eylül 2026

Durum: Yerel geliştirme dilimi tamamlandı. Git etiketi veya yayımlanmış sürüm değildir.

Uygulanan: Go HTTP API, loopback dinleyicisi, üretici Bearer anahtarı, olay kabul/okuma, PostgreSQL migration'ları, iki kontrollü demo hedefi, olay + teslimat işlerinin tek transaction'da yazılması, istek sınırları ve OpenAPI taslağı.

Doğrulama ortamı: Go 1.27.1 Windows/amd64; PostgreSQL 17.11 yalnızca yerel test için çalışma alanındaki geçici araç klasöründen `127.0.0.1:54329` üzerinde çalıştırıldı. Genel PostgreSQL kurulum prosedürü kullanıcı makinesi için henüz standartlaştırılmadı.

Geçen kontroller:

- `go vet ./...` temiz.
- `TEST_DATABASE_URL` verilerek `go test -count=1 ./...` geçti. PostgreSQL testleri her seferinde yalnızca kendi geçici şemasını oluşturup kaldırdı.
- Migration CLI ilk ve ikinci çalıştırmada başarılı oldu.
- Gerçek API süreç testinde yetkisiz GET `401`, örnek POST `202`, olay GET `200` döndü. İki hedef için iki `pending` işi görüldü.
- API süreci kapatılıp açıldıktan sonra aynı olay kimliği ve iki işi okunabildi.
- Yerel test PostgreSQL'i kapatınca yeni olay POST isteği `503 storage_unavailable` döndürdü; `/livez` süreç çalıştığı için `204` kaldı. Test PostgreSQL ve API süreçleri doğrulama sonunda kapatıldı.
- Gerçek PostgreSQL testi: geçersiz ikinci hedef hiç kayıt bırakmadı; ikinci teslimat INSERT'inde enjekte edilen hata ilk teslimatı ve olayı geri aldı.
- OpenAPI YAML dosyası ayrıştırılabildi.

Bilinen sınırlar: Henüz worker ve imzalı HTTP gönderimi yoktur. Aynı POST iki olay yaratır. `pending` işler işlenmez; bu beklenen v0.1 davranışıdır. Yerel test veritabanının kalıcılığı, yedek veya üretim güvenliği için bir iddia değildir. Kaynaklar henüz kullanıcının GitHub reposuna bağlanmadı.

Sıradaki küçük görev: HR-007 — tek worker ve bir girişimlik teslimat geçmişi. İmza protokolü ile örnek alıcı HR-008'dir.
