# HR-024 — Docker ve Compose yerel demosu

25 Eylül 2026. Tek çok aşamalı Go image'ı API, worker, migration ve iki demo alıcısı için kullanıldı; son image root olmayan `65532:65532` kullanıcısıyla çalışıyor. Compose PostgreSQL 17'yi kalıcı volume'da tutuyor, migration'ı ayrı iş olarak çalıştırıyor ve sağlık koşullarına göre diğer süreçleri açıyor. API yalnızca host loopback portu `8080` üzerinden yayımlanıyor. Gizli değerler git/build dışında rastgele oluşturulan `.env.compose` dosyasında; kaydedilmiş image arşivinde bu beş değerin hiçbiri bulunmadı.

Gerçek Docker Desktop Linux motorunda image build ve Compose açılışı geçti. `scripts/smoke-compose.ps1` iki hedefli yeni olayla başarıyla tekrar çalıştırıldı. API isteğiyle açılan ilk olayın iki teslimatı `succeeded` oldu. Worker `SIGKILL` ile durduruldu; worker kapalıyken açılan ikinci olay `pending` kaldı ve yeniden başlatılan worker ile `succeeded` oldu. `docker compose down` ve `up -d` sonrasında iki olay da okunabildi; migration sayısı 18 kaldı. Bütün uygulama container'ları aynı image kimliğini kullandı. [Çalıştırma rehberi](../compose.md).

Bu yerel test üretim kurulumu, otomatik yedek, dış HTTPS alıcısı veya Kubernetes doğrulaması değildir.
