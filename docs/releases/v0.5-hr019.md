# HR-019 — anahtar yaşam döngüsü ve kaynak sınırları

24 Eylül 2026. Dış HTTPS hedefi yalnızca sunucuda yüklü sürümlü `key_id` ile oluşturulur veya güncellenir. Gizli anahtar ham baytları Git dışı dosyada kalır; DB'de ve API'de sadece kimliği bulunur. Teslimat kaydındaki anahtar kimliği snapshot olduğu için rotasyon geçmiş işleri değiştirmez. Varsayılan `public` profili iki yerel HTTP demosunu reddeder; `.env.example` ve mevcut yerel `.env` açık `demo` profilini kullanır.

API kabul limiti süreç başına 20/s, ani 20; yönetici değişikliği 5/s, ani 5. Worker gönderimi hedef başına süreçte 5/s, ani 2; toplam eşzamanlılık mevcut 1–16 sınırıyla kontrol edilir. Bu limitler çok süreçli kurulumda ortak kota oluşturmaz. Depolama ve bağlantı hataları logda yalnızca sabit hata türü olarak yer alır.

Gerçek PostgreSQL testi v1/v2 anahtar kimliği snapshot'ını ve farklı sürümde yeni teslimatı doğrular. Alıcı testi iki sürümün aynı geçiş penceresinde doğrulandığını, v1 kaldırıldığında reddedildiğini ve deduplication kayıtlarının iki teslimatla sınırlı kaldığını gösterir. HTTP testi kimlik ayrımını, dış hedef için anahtar zorunluluğunu, fazla kabul isteğinde `429` yanıtını ve hata metnindeki gizli işaretleyicinin log/yanıta sızmadığını kapsar. Hedef URL ve DNS/IP testleri HR-018'de; gerçek internet alıcısına test isteği gönderilmedi.
