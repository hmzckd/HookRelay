# v0.2 yerel teslimat kaydı — 23 Eylül 2026

Durum: Yerel geliştirme dilimi tamamlandı. Git etiketi veya yayımlanmış sürüm değildir.

Uygulanan: Ayrı worker süreci, PostgreSQL'de tek worker kilidi, `pending → processing → succeeded/failed` geçişleri, girişim geçmişi ve sayfalı okuma API'si, iki sabit localhost hedefe HMAC-SHA256 imzalı HTTP POST, imzayı doğrulayan demo alıcısı, süre/yanıt/yönlendirme sınırları. İmza ve garanti sınırı [teslimat sözleşmesinde](../delivery-semantics.md).

Doğrulama ortamı: Taşınabilir Go 1.27.1 ve ayrı yerel PostgreSQL 17.11 test örneği (`127.0.0.1:54329`). Kullanıcının yeni kurduğu PostgreSQL 17 hizmeti `127.0.0.1:5432` üzerinde erişilebilir göründü; `hookrelay` rolünün parolası paylaşılmadığı için kullanıcıya ait iki veritabanında bağlantı/migration çalıştırılmadı.

Geçen kontroller:

- `go vet ./...` ve `TEST_DATABASE_URL` ile `go test -count=1 ./...` geçti. Testler gerçek PostgreSQL'de claim, terminal sonuç, geçmiş, tek worker kilidi ve yarım kalmış `processing` görünürlüğünü doğruladı.
- v0.1 veritabanına v0.2 migration'ları uygulandı; üç yeni migration kaydedildi ve iki mevcut `pending` iş korundu.
- Gerçek API + worker + iki demo alıcısı: bir olayın iki işi `succeeded`; iki girişim `204` olarak sorgulandı.
- `-mode error` alıcıyla tek girişim `failed`, HTTP `500`, hata sınıfı `http_500` oldu; otomatik tekrar yapılmadı.
- `-mode slow` alıcıyla tek girişim `failed`, hata sınıfı `timeout` oldu.
- Son imza biçimiyle API + worker + demo alıcısı yeniden çalıştırıldı: tek iş `succeeded`, girişim HTTP `204`, imzasız doğrudan istek `401`. Anahtar/olay/teslimat/girişim üst verisi, gövde ve zaman penceresi testlerinde oynanmış değerler reddedildi; sabit test vektörü doğrulandı.
- İzin verilmeyen hedefe bağlantı kurulmaması, yönlendirmenin izlenmemesi ve büyük alıcı yanıtının sınırlandırılması test edildi.
- OpenAPI YAML ve yerel `.env` yükleme PowerShell betiği ayrıştırıldı; örnek `.env` ile yükleme denemesi geçip test dosyası kaldırıldı.

Bilinen sınırlar: Retry yoktur; `failed` terminaldir. Worker `processing` sırasında çökerse iş askıda kalır ve v0.2 kurtarmaz. Yanıt/sonuç kaybında alıcının ne yaptığı kesin bilinemeyebilir. Alıcı deduplication'ı henüz yoktur. İki hedef dışındaki adresler desteklenmez. Kullanıcının yeni sistem PostgreSQL veritabanlarında son bağlantı doğrulaması, kendi `.env` ayarıyla ayrıca yapılmalıdır.

Sıradaki küçük görev: HR-010 — üretici isteği idempotency anahtarı ve atomik tekrar davranışı. Kontrollü teslimat retry politikası HR-011–012'dir.
